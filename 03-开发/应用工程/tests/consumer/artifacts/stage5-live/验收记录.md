| 验收项 | 结果 | 证据/说明 |
| --- | --- | --- |
| 文字模型处理进度 | 通过 | Live 请求显示“正在理解你的问题”及服务端进度步骤；截图 `03-live-text-progress.png`。 |
| 图片读取中 | 通过（修复后） | 发送前进入独立的“图片读取中…”锁定态；该状态对小图短于单次截图窗口，使用新增组件测试稳定覆盖。 |

| 图片失败 | 通过 | Live 失败显示“识别失败”和公开错误文案，不展示内部错误；截图 `06-live-image-failure-retry.png`。 |

| 停止生成 | 通过 | 停止后显示“已停止生成”，输入框和发送能力恢复，未出现确认/成功卡；截图 `04-stop-restored.png`。 |
| 网络失败保留输入 | 通过 | Live 服务失败后保留原始文字、图片及重试请求快照，仅显示公开错误。 |

| 窄屏 | 通过 | 320×700 视口无横向溢出，手机框全屏，三个快捷入口与输入区可用；截图 `02-narrow-320x700.png`。 |
| reduced motion | 通过 | `prefers-reduced-motion: reduce` 下全局关闭平滑滚动，并将动画和过渡压缩到 0.01ms；新增测试覆盖。 |

| 延迟期重复提交保护 | 通过 | 请求期间发送、重试按钮锁定；附件读取阶段新增单飞锁，停止生成不触发写操作。 |

## 说明

Live 环境能建立请求并返回服务端进度事件，但本次文字与图片请求最终均进入公开的“服务暂时不可用”状态。因此，“图片完成”使用同一 04 消费者实现和稳定 Mock 终态复验；未把 Live 失败误记为模型成功。验收过程中未读取或记录任何密钥值。
