# 02 对话任务简报：业务工具与售后工作流

## 可直接发给新对话的首条消息

> 你负责“客服 Agent 实验室”的 PCMP、OMS、WMS、TMS、CRM Mock Adapter 和售后工作流。请在 `feat/business-workflows` 对应 worktree 工作。先阅读并行计划、PRD 和当前 adapters。只修改本简报允许的目录，不要改消费者页面、知识页面、公共 contracts 或总编排器；需要契约变更时提交变更申请。

## 目标

把零散返回值升级为正式接口形态，使查询、草稿、确认、写入、失败和来源追踪都可测试、可被运营台读取。

## 允许修改

- `src/lib/domain/**`
- `src/lib/adapters/**`（知识 Adapter 除外）
- `src/lib/mock-data/**`
- `src/lib/stores/business/**`
- `tests/business/**`

## 功能清单

- PCMP 产品主数据。
- OMS 订单和可变更状态。
- WMS 出库 / 履约事件。
- TMS 物流轨迹、客服电话和催办。
- CRM 退换申请、维修 / 安装工单、人工接管。
- 订单物流聚合、订单变更、物流催办、退换、报修、工单查询。
- 所有写操作支持草稿、编辑、确认令牌、幂等键和最终快照。
- 注入 success、empty、timeout、business_error、system_error。
- Store 的 list / get / reset，供运营台和 Evals 使用。

## 关键测试

- 查询前身份确认。
- 不可变更订单返回业务拒绝。
- 相同幂等键重复提交只创建一条记录。
- 超时和系统失败不返回伪造成功编号。
- 退换和工单保存用户最终编辑内容。
- 工具结果包含来源系统、记录 ID、更新时间和状态码。

## 不做

- 不决定意图。
- 不生成消费者自然语言回答。
- 不实现运营台页面。

## 交付

- 工具目录、接口说明和错误矩阵。
- 每个主要 Adapter 至少成功 / 失败各一项测试。
- 一次独立提交。
