POST `https://opai-console.opple.com/v1/chat/completions`

Header：`Authorization: Bearer <TEXT_MODEL_API_KEY>`

> 安全说明：原文档中的明文密钥已移除。真实密钥只能配置在本地 `.env.local` 或部署平台的密钥管理中，不得提交到 Git。由于密钥曾以明文出现，应在网关侧轮换。

Content-Type：`application/json`

```json
{
  "model": "Qwen3.6-27B",
  "messages": [
    {
      "role": "user",
      "content": "你好啊"
    }
  ],
  "max_tokens": 1000,
  "stream": false,
  "chat_template_kwargs": {
    "enable_thinking": false
  }
}
```

## Qwen3.6 思考模式兼容约束

- 当前欧普 OpenAI Chat Completions 兼容网关要求使用 `chat_template_kwargs.enable_thinking=false` 关闭思考模式。
- 不得改用顶层 `enable_thinking=false`；该字段会被当前网关忽略，可能导致输出 token 全部消耗在 `reasoning_content`，而 `message.content` 为空。
- 客服 Agent 只读取最终可见的 `message.content`，不读取、不保存、不返回模型私有思考内容。
- `max_tokens` 是最终完成内容的上限，当前本地默认为 `1000`，不再为私有思考强制抬高。
